# Задание 3. Концептуальная архитектура открытия депозитов (MVP)

В рамках третьего задания разработана целевая концептуальная архитектура (To-Be) для этапа MVP процесса открытия депозитов в банке «Стандарт».

## Состав файлов задания

Диаграммы подготовлены в формате draw.io (открываются через [app.diagrams.net](https://app.diagrams.net/) или плагин в VS Code / Cursor):

| Файл | Описание |
| --- | --- |
| `ADR.md` | Архитектурное решение (Architecture Decision Record) по шаблону курса: Use Cases, NFR, описание решения, диаграммы, альтернативы и анализ рисков |
| `c4-context.drawio` | C4 диаграмма контекста: люди, системы банка и внешние сервисы (номера стрелок привязаны к UC1–UC10 из ADR) |
| `c4-containers.drawio` | C4 диаграмма контейнеров: детальная архитектура интернет-банка, нового контура заявок/ставок и АБС |

## Ключевые решения архитектуры MVP

1. **Выделение отдельного сервиса «Контур заявок и ставок»**:
   - Реализуется силами команды банка на стеке `.NET` + `MS SQL` рядом с интернет-банком.
   - Заменяет ручной расчет в Excel и почтовые рассылки единым реестром ставок с веб-интерфейсом для сотрудников.
   - Выступает единым источником актуальных ставок для сайта, интернет-банка и кол-центра.
   - Берет на себя хранение заявок, проверку статусов и расчет персонализированных ставок.

2. **Защита ядра интернет-банка (монолита)**:
   - Депозитный модуль встраивается в интернет-банк как отдельный UI-слой, не требуя доработки закрытого ядра платформы подрядчиком (.NET 4.5).
   - Подтверждение заявки по СМС (OTP) реализуется через интеграцию со штатным СМС-шлюзом банка.

3. **Защита и разгрузка АБС (Oracle)**:
   - Каналы взаимодействия с клиентом (сайт, интернет-банк) **не обращаются напрямую к БД или API АБС**.
   - Передача задач на открытие вклада происходит асинхронно через буфер заявок (Transactional Outbox в MS SQL) и специализированный Адаптер АБС.
   - На этапе MVP сотрудник бэк-офиса подтверждает условия и проводит открытие вклада в штатном клиенте Delphi АБС.
   - Выбранная граница сервисов позволяет через 1 год перейти к полностью автоматическому открытию вклада без участия бэк-офиса, не меняя клиентские каналы.
