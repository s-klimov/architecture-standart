# Задание 3. Концептуальная архитектура открытия депозитов (MVP)

Банк «Стандарт», to-be для MVP: заявка онлайн, учёт по-прежнему в АБС.

Открыть: [app.diagrams.net](https://app.diagrams.net/) → Open Existing Diagram.

| Файл | Что внутри |
| --- | --- |
| `ADR.md` | ADR по шаблону курса: Use Cases, NFR, решение, альтернативы |
| `c4-context.drawio` | C4, уровень контекста. Номера стрелок = UC из ADR |

## Вывод для команды ЦТ и менеджера проекта

В MVP делают **команда ИБ банка** (модуль + сервис заявок/ставок), **команда АБС** (адаптер и открытие вклада), **сайт**, **КЦ подрядчика** и **СМС**. Подрядчик ядра ИБ и партнёрский КЦ не нужны. Каналы не ходят в Oracle; АБС не служит витриной ставок.
