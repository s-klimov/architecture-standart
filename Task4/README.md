# Задание 4. Передача ставок в кол-центр

Дополнение к MVP депозитов: операторы КЦ банка и партнёрского КЦ консультируют клиентов по **актуальным базовым ставкам** без второго Excel и без API у партнёра.

## Вывод для менеджера проекта

1. Сначала команда банка публикует ставки в контуре и открывает API каталога.
2. КЦ банка подключает виджет к этому API — оператор называет те же цифры, что сайт.
3. Затем экспортёр кладёт файл в канал выкладки; партнёр забирает файл и учит скрипты.
4. Заявки с сайта партнёру не отдаём: он разгружает телефон, не контур ПДн.
5. Автооткрытие вклада и «только фронт» в отделении — синие полосы на горизонте года, после живого адаптера АБС.
