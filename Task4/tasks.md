# Перечень архитектурных задач (WBS)

Перечень задач сформирован на основе архитектурных решений Заданий 3 и 4. Номера задач (**T1–T17**) соответствуют полосам на дорожной карте [`roadmap.drawio`](roadmap.drawio).

Задачи разделены на два горизонта:
1. **Горизонт 6 месяцев (MVP и маркетинговая кампания):** запуск онлайн-заявок, единого реестра ставок, витрин и передачи ставок в кол-центры.
2. **Горизонт 12 месяцев (Целевая архитектура):** автоматизация открытия вклада без бэк-офиса, внедрение Apache Kafka и активное резервирование сервисов (99.9%).

## 9. Порядок и зависимости реализации

1. **Критический путь на первые 3 месяца:**
   `T1 (Справочник ставок)` → `T2 (API каталога)` → `T5-T6 (Виджет КЦ банка)` и `T10 (Сайт)` / `T11 (Интернет-банк)`.
2. **Критический путь интеграции партнёра:**
   `T2 (API каталога)` + `T4 (SFTP)` → `T3 (Экспортёр файлов)` → `T8-T9 (Приём файла партнёром)`.  
   *Запуск маркетинговой кампании возможен только после завершения T6 и T9.*
3. **Критический путь целевого решения (7–12 месяцев):**
   `T12 (Адаптер АБС на MVP)` → `T14 (Автооткрытие вклада)` → `T15 (Оптимизация в отделениях)` + `T16 (Kafka)` → `T17 (99.9% / 2 ЦОД)`.
