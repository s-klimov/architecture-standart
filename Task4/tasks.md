# Крупные задачи по системам (вход для roadmap)

Источник границ — ADR этого задания. Номера **T1–T18** совпадают с полосами на `roadmap.drawio`.
Задачи горизонта 6 месяцев нужны, чтобы запустить MVP заявки **и** консультацию по ставкам до маркетинговой кампании.
Задачи горизонта года — целевое решение из `CONTEXT.md`: автооткрытие без бэк-офиса.

Зависимости (коротко): сначала справочник и API каталога, затем виджет КЦ банка и экспортёр, затем приём файла у партнёра. Сайт, модуль ИБ и адаптер АБС идут параллельно после T1/T2. Автооткрытие не начинать, пока адаптер АБС не отработал на ручном потоке.

## Что сознательно не делаем в этих задачах

- Не кладём справочник ставок в Oracle АБС.
- Не даём партнёру API и не отдаём ему заявки с сайта.
- Не дорабатываем ядро интернет-банка силами подрядчика.
- Не обещаем 99,9% и Kafka как условие старта кампании.
